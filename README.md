# Algorithmic Strategies Mini Project

This project implements four real-world problems using different algorithmic strategies.

## Problems Implemented
1. TV Commercial Scheduling (Greedy Algorithm)
2. Knapsack Problem (Dynamic Programming)
3. Sudoku Solver (Backtracking)
4. Password Cracker (Brute-Force)

## How to Run
1. Clone this repository
2. Create virtual environment: `python -m venv venv`
3. Activate virtual environment
4. Install requirements: `pip install -r requirements.txt`
5. Run Jupyter: `jupyter notebook`
6. Open `algo_strategies_notebook.ipynb`

## Dependencies
- Python 3.8+
- matplotlib
- numpy
- memory_profiler
- jupyter
